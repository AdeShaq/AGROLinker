# **App Name**: AgroLinker

## Core Features:

- Streamlined Onboarding: Clear and simple onboarding process for farmers and helpers, guiding them through account creation and profile setup, available both on web and USSD.
- Request Posting: Easy-to-use form for farmers to post help requests with detailed descriptions, location, and preferred reward.
- Instant Notifications: Real-time SMS notifications to alert helpers of new requests in their area and skill set.
- Task Confirmation: Simple confirmation process for farmers to mark tasks as completed, triggering reward disbursement.
- Helper Availability: Profile management feature for helpers to manage availability status, skillsets, and contact information.
- AI-powered Matching: An AI tool will attempt to improve the matching process by using location and task data from previous jobs in order to automatically identify helpers best suited for particular tasks, and further suggest appropriate compensation.

## Style Guidelines:

- Primary color: Earthy green (#6B8E23) to evoke nature and agriculture.
- Background color: Light beige (#F5F5DC) for a clean, natural feel.
- Accent color: Warm yellow (#FFC125) for CTAs and important notifications.
- Body and headline font: 'PT Sans', a humanist sans-serif with a modern look.
- Simple, intuitive icons to represent task types and actions.
- Clean, uncluttered layout with a focus on usability for users with varying levels of tech literacy.
- Subtle animations for task confirmations and reward notifications.
